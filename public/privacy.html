Privacy Policy

Language: English • Effective Date: October 2026
Executive Summary: NetPocket Cybersecurity is an air-gapped, zero-telemetry application. It does not request network permissions, contains no analytics or tracking code, and never transmits or shares any user information.

1. Zero Internet Permission (Air-Gapped Architecture)

NetPocket is built for sensitive and isolated cybersecurity environments. The Android release package does not declare or request the android.permission.INTERNET permission. It has no backend API, no cloud servers, no remote content distribution networks (CDNs), and no external font or script dependencies.

2. Zero Data Collection & Zero Telemetry

  • No Personal Identifiers: We do not collect names, email addresses, phone numbers, or account credentials.
  • No Telemetry or SDKs: There are zero third-party software development kits (SDKs), analytics trackers, crash reporters (e.g., Firebase, Sentry), or advertising networks.
  • No Technical Identifiers: We do not read or record IMEI, Android ID, MAC address, advertising ID, or hardware serial numbers.

3. Volatile RAM Processing

All security and network computations—including cryptographic hashing (MD5, SHA-1, SHA-256), Base64 / Hex / Binary encoding and decoding, IOC defanging and refanging, IPv4 CIDR subnetting, and Linux chmod permission evaluations—are performed purely in local volatile memory (RAM). When the application is closed or cleared from recent tasks, all transient inputs and calculated results are completely erased from memory. They are never written to disk or device logs.

4. Local On-Device Storage

The application only utilizes standard local browser storage (localStorage) to persist non-sensitive user UI preferences: active interface theme (Tactical Dark or Field Light), display language (English, Spanish, or Portuguese), default CIDR slider prefix, and user-pinned port or event IDs (favorites). No IP addresses, logs, or payload strings are ever saved to disk.

5. Third-Party Sharing

Because no data is ever collected or transmitted, no information is sold, rented, shared, or transferred to any third party under any circumstances.

Política de Privacidad

Idioma: Español • Fecha de entrada en vigor: Octubre de 2026
Resumen Ejecutivo: NetPocket Cybersecurity es una aplicación aislada ("air-gapped") y con cero telemetría. No solicita permisos de red, no contiene código de analítica o rastreo, y nunca recopila, transmite ni comparte información alguna del usuario.

1. Cero Permisos de Internet (Arquitectura Aislada)

NetPocket está diseñada para entornos de ciberseguridad sensibles y aislados. El paquete de lanzamiento de Android no declara ni solicita el permiso android.permission.INTERNET. No dispone de API backend, servidores en la nube, redes de distribución de contenido (CDN) ni dependencias externas de fuentes o scripts remotos.

2. Cero Recopilación de Datos y Cero Telemetría

  • Sin Identificadores Personales: No recopilamos nombres, correos electrónicos, números de teléfono ni credenciales.
  • Sin Telemetría ni SDKs: La aplicación contiene cero kits de desarrollo (SDK) de terceros, herramientas de análisis, rastreadores de fallos (ej. Firebase, Sentry) o redes de publicidad.
  • Sin Identificadores Técnicos: No recopilamos ni leemos IMEI, Android ID, dirección MAC, ID de publicidad ni números de serie del hardware.

3. Procesamiento en Memoria Volátil (RAM)

Todos los cálculos de seguridad y redes—incluyendo hashes criptográficos (MD5, SHA-1, SHA-256), codificación y decodificación Base64 / Hex / Binario, desarmado ("defang") de IOCs, subnetting IPv4 CIDR y auditoría de permisos chmod—se realizan exclusivamente en la memoria RAM volátil local. Al cerrar la aplicación, todas las entradas y resultados se borran por completo de la memoria. Nunca se escriben en disco ni en registros del sistema.

4. Almacenamiento Local en el Dispositivo

La aplicación únicamente emplea el almacenamiento local estándar (localStorage) para guardar preferencias no sensibles de la interfaz de usuario: tema visual (Oscuro Táctico o Claro de Campo), idioma de visualización (inglés, español o portugués), prefijo CIDR por defecto y elementos marcados como favoritos (puertos o eventos fijados). Ninguna dirección IP, log o payload analizado se guarda en disco.

5. Compartición con Terceros

Dado que ningún dato es recopilado o transmitido, no se vende, alquila, comparte ni transfiere información a terceros bajo ninguna circunstancia.

O NetPocket foi projetado para ambientes sensíveis e isolados de cibersegurança. O pacote de lançamento para Android não declara nem solicita a permissão android.permission.INTERNET. O aplicativo não possui API remota, servidores na nuvem, redes de distribuição de conteúdo (CDNs) ou scripts externos.

2. Zero Coleta de Dados e Zero Telemetria

  • Sem Dados Pessoais: Não coletamos nomes, e-mails, telefones ou credenciais de acesso.
  • Sem Telemetria ou SDKs: Não há bibliotecas de terceiros, ferramentas de análise estatística, rastreadores de falhas (como Firebase ou Sentry) ou redes de anúncios.

5. Compartilhamento com Terceiros

Como nenhum dado é coletado ou transmitido, nenhuma informação é vendida, alugada ou compartilhada com terceiros em qualquer hipótese.
